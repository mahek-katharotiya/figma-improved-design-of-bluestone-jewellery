## Experiment 5: Heuristic Evaluation Based on Nielsen’s 10 Principles
A structured peer review and heuristic evaluation of the **AURELLE Luxury Jewellery Platform** 
using Nielsen’s 10 Usability Principles. The evaluation assesses system feedback, error prevention, 
user freedom, and visual hierarchy on a 0–5 severity scale, validating key design solutions such as the 
live gold rate ticker, transparent itemized price breakdown (*Net Gold Weight + Making Charges + GST*),
and 1-click doorstep return portal.

## Experiment 6: Remote Usability Testing via Maze
Unguided quantitative and qualitative usability testing of the interactive Figma prototype using the 
**Maze remote testing platform**. Measures core performance metrics—**Direct Success Rate, Misclick Rate, 
and Average Duration**—across four key e-commerce missions (*Men's Gifting Navigation, AR Virtual Try-On Fitting,
GPS Store Locator Search, and Price Breakdown Verification*) to drive iterative UI refinements based on heatmaps and 
user click paths.

## Experiment 7: Inclusive & Accessible Design (WCAG 2.1 AAA Compliance)
An adaptive redesign of the AURELLE platform optimized for users with diverse visual, hearing, motor, 
or cognitive impairments. Grounded in **WCAG 2.1 AAA guidelines**, features include an Accessibility Settings Drawer,
"Listen to Description" text-to-speech buttons, large `+` / `-` stepper controls for AR fitting, high-contrast mode,
screen-reader optimized ARIA/alt-text, closed captions for video consultations, and low-stimulation motion toggles.

## Low-Fidelity Wireframes (Lo-Fi Blueprints)
Structural layout frames and spatial organization diagrams for both **Desktop Web** and **Mobile App** interfaces across four core screens:
* **Global Homepage**: Top Live Gold Rate ticker, minimalist header bar, hero display area, and 3×4 product grid container.
* **Consolidated Hamburger Navigation Drawer**: Slide-out panel blueprint featuring 5 accordion categories (*Jewellery, Collections, New & Trending, Gifting, Aurelle Services*).
* **Product Detail Page (PDP) & AR Try-On**: Dual-panel specification view with transparent price breakdown modal and camera-based AR Virtual Try-On overlay.
* **Store Locator ("Stores Near Me")**: Split view with postcode search, nearby boutique inventory list, and GPS map pin layout.

## High-Fidelity Wireframes (Hi-Fi Visual System)
Polished visual UI mockups incorporating AURELLE's luxury design system across Desktop and Mobile viewports:
* **Brand Aesthetics**: Deep Dark Forest Green (`#173B2E`), Champagne Gold (`#C7A45D`), and Warm Cream Beige (`#F4EBDD`).
* **Display Policy**: Strict **No-Human-Model Policy** displaying jewellery exclusively on dark velvet busts and acrylic pedestals.
* **Interactive Elements**: Live updating gold rate ticker, plain magnifying glass search icon, avatar profile sign-in drawer, active AR camera viewport
* with live scale/drape sliders, and real-time boutique stock badges.
